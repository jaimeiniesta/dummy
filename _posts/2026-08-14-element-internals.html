Each section below is a single behaviour that changed between axe-core 4.12 and 4.13. Scan this page with both versions and diff the results.

1. Element Internals role, with aria-label on the host

4.12: aria-prohibited-attr violation — aria-label is reported as not allowed, because axe cannot see the progressbar role set through Element Internals.
4.13: passes. This is axe-core issue #4259.

2. Same component, internals held in a private class field

4.12 and 4.13: still an aria-prohibited-attr violation. The component stores its internals in a #internals private field, which nothing outside the class can read. Include this one — it is the control case that shows the limit of the feature.

3. Attribute that is invalid for the internals role

4.12: not flagged. Axe sees no role, so it has nothing to validate the attribute against.
4.13: aria-allowed-attr violation — aria-checked is not allowed on progressbar. A genuine issue that 4.12 missed.

4. Form-associated custom element with a real label

4.13: the accessible name resolves through internals.labels. Nothing should be reported here. Useful as a negative control.

5. role="image" without an accessible name

4.12: not flagged — the rule selector only matched role="img".
4.13: role-img-alt violation. The selector now also matches role="image", which browsers treat as equivalent.

6. Deprecated ARIA attribute

Draggable card

4.12: passes.
4.13: aria-allowed-attr needs-review item. Same applies to aria-dropeffect. Check this lands in the incomplete bucket, not in violations.

7. Whitespace alt on a presentational image

4.12: image-alt violation.
4.13: passes.

8. Role on a summary outside details

Standalone summary

4.12: aria-allowed-role issue.
4.13: passes.

9. Named label element

4.12: passes.
4.13: aria-prohibited-attr violation — label and body can no longer carry an accessible name.

10. Section with a non-landmark role

Filter controls
More filter controls

4.12: landmark-unique issue.
4.13: passes — sections with a non-landmark role are no longer treated as landmarks.
